OBJETIVO
--------
Disponibilizar arquivos de um computador para outros da rede local.

QUANDO USAR
-----------
Quando a internet cair, mas os aparelhos continuarem na rede local.
Quando quiser distribuir manuais ou mapas sem depender de nuvem.
Quando precisar testar uma página antes de publicá-la.

NAO USE QUANDO
--------------
Quando os dispositivos não estiverem na mesma rede local.
Não use para dados sigilosos: sem senha, qualquer pessoa na rede lê tudo.

MATERIAIS
---------
- Computador com Python 3 instalado.
- Rede local: roteador, switch ou cabo direto entre os aparelhos.
- Pasta com os arquivos e outro dispositivo com navegador para testar.

PROCEDIMENTO
------------
1. Ligue os dispositivos na mesma rede, por cabo ou Wi-Fi.
2. Descubra o IP local com ip addr e anote o que começa com 192.168 ou 10.
3. Crie a pasta /srv/compartilhado e copie os arquivos para ela.
4. Entre na pasta com: cd /srv/compartilhado
5. Inicie com: python3 -m http.server 8000 --bind 0.0.0.0
6. Mantenha o terminal aberto; o servidor para ao fechá-lo.
7. No outro dispositivo, abra o navegador.
8. Digite o IP anotado, dois pontos e 8000 na barra de endereço.
9. Abra um arquivo e confira se o conteúdo aparece.
10. Para encerrar, pressione Ctrl+C no terminal.

ATENCAO
-------
O servidor do Python não serve para uso profissional: tem só verificações
básicas de segurança. Qualquer pessoa na rede pode ver e baixar arquivos.
Não coloque senhas ou documentos pessoais na pasta.
O servidor segue links simbólicos e pode expor arquivos fora da pasta.
Para se o computador dormir ou o terminal fechar. Precisa de energia.

SE NAO TIVER
------------
Sem Python, use outro servidor HTTP local instalado no computador.
Sem roteador, ligue por cabo direto e use IPs fixos na mesma faixa,
por exemplo 192.168.1.1 e 192.168.1.2.
Sem rede, copie os arquivos em pendrive para cada dispositivo.

COMO SABER QUE DEU CERTO
------------------------
O navegador do outro dispositivo mostra a lista de arquivos da pasta.
O terminal registra um acesso a cada arquivo aberto.
